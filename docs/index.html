What it is

Traditional campus dashboards tell you what is happening. GENIEPOLIS lets students ask what if? You explore an interactive 2.5D digital twin of BMS College of Engineering, then a Genie grants you three independent wishes. For each one it plays Akinator — asking a few narrowing questions — confirms what you really meant, then simulates how that single decision ripples across the entire campus.

🧞 The Genie narrows

3–6 quick questions turn a vague wish into a structured scenario. It doesn't just answer — it interrogates.

🌀 The ripple

One change → class timing → buses → traffic → parking → cafeteria → faculty → workers → energy. Animated, step by step.

🫀 Campus Pulse

Repeated wishes stop being isolated complaints. At 50+ requests a wish becomes a campus signal.

The journey

Every wish runs the full loop before the next one begins.

See campus→ Meet Genie→ Make wish→ Genie narrows→ Confirm→ ✨ Make it happen→ Ripple→ Direct + indirect impacts→ Before / after→ Risks + benefits→ Alternatives→ Wish complete

Architecture

Genie interprets and explains. A deterministic Python engine owns every number — the LLM never does the math.

User→Streamlit UI→Databricks Genie — interpret · clarify · retrieve · explain
→Structured scenario JSON→Deterministic simulation engine — before/after, ripple, risk/benefit
→Ripple graph→Campus visualization→Genie explanation of the results

Databricks

Genie Agent (Conversation API) + Unity Catalog: 16 synthetic tables incl. an impact_relationships butterfly-effect graph.

Python

12 deterministic scenario handlers. Simple, readable formulas: new = base × (1 + factor).

Streamlit

The game-like UI, custom CSS, the 12-screen journey, three-wish state machine.

Plotly

Fast 2.5D campus map — clickable buildings, live conditions, ripple highlighting.

Run it yourself

git clone https://github.com/pranavsundhar404/geniepolis.git

cd geniepolis && pip install -r requirements.txt

streamlit run app.py

Opens in Demo fallback mode with zero config. Add a .env with your Databricks host, token and Genie space ID to connect the real Genie agent — see DATABRICKS_SETUP.md.

All operational data is synthetic demonstration data — not real institutional data
